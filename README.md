# Trading Interview Practice

Static copy of the Trading Interview Practice app (trading interview question bank, lessons, trainers, market games, firm guides).

- `index.html`, `app.js`, `*.css`: the built app
- `data/`: question banks
- `src/`: sources (`*.txt`) and build/test scripts — see `docs/build-notes.md`
- `pyodide/`, `clang/`: in-browser Python and C++ runtimes (pyodide 0.26.4, @yowasp/clang 22.0.0-git20695-13)
- `docs/`: build notes

Note: firm logos in `logos/` are the firms' trademarks, used here for personal practice only.
